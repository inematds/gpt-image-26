GPT Image 2.6 in practice

What’s new in OpenAI’s image model, which settings to use for each task, what it costs, and where it still gets things wrong.

Start the guide View on GitHub
In short

GPT Image 2.6 is OpenAI’s latest image model. It already runs in ChatGPT and Codex (OpenAI’s coding assistant), and you can also use it through the API, which lets programs and scripts access the model. This guide is for people who create images for posts, ads, logos, stories, or videos and want to make the most of its new features: the complexity setting (how much the model plans before drawing), animated GIFs, vector logos (SVG), and editing only the area you mark. You only need a ChatGPT account to use it; for the API, you need an OpenAI API key (billed separately from your subscription) and this repository’s gerar.py script, which only requires Python.

What it is

A model that plans before it draws

There are two models in the API, with the same features in both. You can’t choose in ChatGPT: version 2.6 is already there.

🧠 Complexity

New complexity setting (low, medium, high): how much the model plans object placement, how people interact, and how to handle several instructions at once. Default: high. There’s no separate charge.

🎞️ GIF and SVG

Generate a looping animated GIF (2 to 16 frames) or a vector SVG logo that you can open in an editor and enlarge without losing quality.

⭕ Markup editing

Circle where you want a change in the image, describe what you want, and the model edits only that area. Regular edits are also more faithful: the rest stays in place.

ModelPurposeWhen to use it
gpt-image-2.6-flareSmaller and fasterDrafts, quick posts, many variations, or when response time matters.
gpt-image-2.6-sunburstBase model, more detailFinal artwork, ads, precise edits, small text, demanding layouts.
How to think

One thing at a time

The golden rule for 2.6: separate “planning” from “detailing.” Complexity handles the layout; quality handles the finish. Change one setting at a time and compare.

Choose the model→ Prompt in sections→ Layout right? (complexity)→ Details right? (quality)→ Check hands, text, reflections→ Edit one thing at a time
What went wrongWhat to change
Object in the wrong place, misspelled word, people arranged nonsensicallyIncrease complexity (keep quality the same).
Layout is right, but small text is unreadable or the texture looks poorIncrease quality (keep complexity the same).
A small edit changed other partsUse complexity low and list what should stay the same.
It takes too longSwitch to Flare or lower quality; use xhigh and max only if they solve a problem.
Prerequisites

What you need

Most people only need ChatGPT. The API is for people who want to automate tasks.

💬 ChatGPT

A ChatGPT account (browser, computer, or phone). Version 2.6 is also available in Codex. Just ask for an image in the conversation.

🔑 API (optional)

Create a key at platform.openai.com/api-keys and add credit to your API account: it’s billed separately; your ChatGPT subscription doesn’t cover it.

# Mac and Linux
export OPENAI_API_KEY="sua-chave"
# Windows (PowerShell)
$env:OPENAI_API_KEY="sua-chave"

🐍 Starter kit script

Python 3.9 or newer (python.org); no package installation needed. Download the kit with Git or as a ZIP, then open a terminal in the folder (Mac: Terminal app; Windows: PowerShell). On Windows, replace python3 with py.

git clone https://github.com/inematds/gpt-image-26
cd gpt-image-26
python3 gerar.py --help
How-to guide · step by step

From your first prompt to GIFs and logos

Steps 1 to 6 work in ChatGPT. Step 7 does the same thing through the API. All prompts are in prompts.md (in Portuguese).

1

Write the prompt in sections

State the type of artwork and how you’ll use it, then describe the scene, subject, details, and restrictions. Put any required text in quotation marks, and say what you don’t want.

Create a portrait-format festival poster.
Scene: beach at sunset, golden light.
Details: bold typography, the same font throughout the poster.
Restrictions: no logo, no watermark, no other text.
Text (exactly): "SEA FESTIVAL 2027"
2

Adjust complexity and quality, one at a time

In ChatGPT, describe what you want in plain language (“plan the composition carefully,” “pay close attention to the small lettering”). In the API, use the complexity field (low, medium, high) and the quality field (auto, low, medium, high, xhigh, max; the script uses medium if you don’t specify one). Compare results using the same prompt and changing only one setting.

# via the API (step 7, billed to your account): same prompt, only complexity changes (quality stays the same)
python3 gerar.py "Four dancers form the word LIKE" --complexity low  --quality medium --saida like-low
python3 gerar.py "Four dancers form the word LIKE" --complexity high --quality medium --saida like-high
3

Keep the same character

Describe the features that must not change, and repeat them in each prompt. In ChatGPT, save the photo as a reference with a name, then refer to it by name later.

Save this image as a reference named "Ana".
# in a new conversation:
Use the reference "Ana" and create a video cover with the text "Start today".
4

Create a looping GIF

In ChatGPT, send the image and ask for a sprite sheet (a grid of animation frames): it will draw the frames and assemble the GIF. Give it a starting pose to return to for a smooth loop; ask for more frames to make the animation smoother.

Create a 3x3 sprite sheet of this person blinking and smiling, in a loop.
The last frame returns to the first pose. Static camera. Then assemble the GIF.
5

Ask for the logo in SVG

SVG is vector graphics: you can move, recolor, and enlarge it from phone size to billboard size. Open it in Inkscape or Figma. SVG output is available only for new images (editing doesn’t return SVG).

Original logo for "North Star Bakery". Simple shapes, strong silhouette,
few colors, no gradients. Transparent background. Deliver as SVG.
6

Edit with markup: circle and prompt

In ChatGPT, open the generated image and use the select/mark area tool that appears over it; through the API, use the markup field (step 7). Mark the area and describe the change. Then edit one thing at a time (color, background, lighting, angle), always saying what should stay the same.

Inside the red circle, paint the vase cobalt blue.
Don’t change anything else in the image. Remove the circle from the result.
7

Use the starter kit script with the API

gerar.py builds the request with the correct field names and checks the limits before spending (GIF frame count, dimensions in multiples of 16, SVG for generation only). Run with --seco to see the request without calling the API.

python3 gerar.py 'Poster with the text "SUMMER 2027"' --modelo sunburst --quality high --seco
python3 gerar.py "Bakery logo, simple shapes" --formato svg --fundo transparente
python3 gerar.py "Cat blinks and returns to its starting pose, static camera" --formato gif --quadros 9 --ms 200
# markup with the example photo and circle from OpenAI
python3 exemplos/baixar.py
python3 gerar.py "Paint the vase in the circle blue. Don’t change anything else. Remove the circle." --editar exemplos/cozinha.webp --markup exemplos/circulo.png --complexity low

For your own photo, create circulo.png in a layer editor (Photopea, Figma, GIMP): open the photo, create a new layer, draw the red circle, hide the photo layer, then export only the circle as a transparent-background PNG in the same size as the photo. Markup applies to the first image and can’t be combined with a mask. The photo can be PNG, JPG, or WebP.

Limits and cost

Where it still gets things wrong and what it costs

It’s a real improvement in planning, text, crowds, GIFs, and vector graphics. Still, always check the result before using it. The four examples below come from hands-on tests with 2.6; OpenAI lists text, consistency, and exact positioning as general limitations.

✋ Hands and wrists

It can still generate too few fingers or a twisted wrist, even at high quality.

📏 Proportions

Objects can be the wrong scale: Jupiter is too small, or cards are different sizes.

🪞 Reflections

A mirror may show something it shouldn’t or leave out objects in the scene.

🔢 Counting

“Exactly seven” can turn into five. If the number matters, check it.

Pricing

OpenAI charges by token, the unit it uses to measure what goes into and comes out of the model: a square image uses a few hundred to a few thousand tokens, depending on quality. Per token, 2.6 costs the same as 2.5 (output images at $30 per million). The difference is how many tokens it uses: at low and medium quality, 2.6 uses more; from high upward, it uses the same amount.

Output cost for one 1024×1024 image, in US cents, according to OpenAI’s official calculator (checked on 07/11/2026). At low quality, 2.6 costs 4.2× more than 2.5; at medium, 3.3× more; from high upward, the same. The prompt text and input images add a little more.

Budget-friendly approach: make drafts with Flare at low or medium quality; use Sunburst at high quality only for the final piece. Complexity and markup have no extra charge; SVG is billed for the reference image plus the vector tokens.
