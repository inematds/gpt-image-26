GPT Image 2.6 in practice

What’s new in OpenAI’s image model, which settings to use for each task, what it costs, and where it still gets things wrong.

Start the guide View on GitHub
In brief

GPT Image 2.6 is OpenAI’s latest image model. It already runs inside ChatGPT and Codex (OpenAI’s coding assistant), and you can also use it through the API, which lets programs and scripts access the model. This guide is for anyone creating images for posts, ads, logos, stories, or videos who wants to make the most of the new features: the complexity setting (how much the model plans before drawing), animated GIFs, vector logos (SVG), and edits limited to the area you mark. All you need to use it is a ChatGPT account; for the API, you’ll need an OpenAI key (billed separately from your subscription) and this repository’s gerar.py script, which only requires Python.

What it is

A model that plans before it draws

There are two models in the API, with the same features in both. You can’t choose in ChatGPT: 2.6 is already there.

🧠 Complexity

New complexity setting (low, medium, high): how much the model plans object placement, interactions between people, and multiple instructions at once. Default: high. No separate charge.

🎞️ GIF and SVG

Creates looping animated GIFs (2 to 16 frames) and vector SVG logos that you can open in an editor and enlarge without losing quality.

⭕ Markup editing

Circle the area you want to change, describe the edit, and it changes only that part. Regular edits are also more faithful: everything else stays in place.

ModelBest forWhen to use it
gpt-image-2.6-flareSmaller and fasterDrafts, quick posts, many variations, or when response time matters most.
gpt-image-2.6-sunburstBase model, more detailFinal assets, ads, precise edits, small text, demanding layouts.
How to think

One thing at a time

The golden rule for 2.6: separate “planning” from “detailing.” Complexity sorts out the layout; quality handles the finish. Change one setting at a time and compare.

Choose the model→ Prompt in sections→ Is the layout right? (complexity)→ Are the details right? (quality)→ Check hands, text, reflections→ Edit one thing at a time
What went wrongWhat to change
Object in the wrong place, misspelled word, people that don’t make senseIncrease complexity (keeping quality the same).
Layout is right, but small text is unreadable or the texture looks poorIncrease quality (keeping complexity the same).
A small edit changed other parts tooUse complexity low and list what should stay the same.
It takes too longSwitch to Flare or lower quality; use xhigh and max only if they solve a specific problem.
Requirements

What you need

For most people, ChatGPT is all you need. The API is for automating tasks.

💬 ChatGPT

A ChatGPT account (browser, computer, or phone). 2.6 is also available in Codex. Just ask for an image in the conversation.

🔑 API (optional)

Create a key at platform.openai.com/api-keys and add credit to your API account: it’s billed separately, and your ChatGPT subscription doesn’t cover it.

# Mac and Linux
export OPENAI_API_KEY="sua-chave"
# Windows (PowerShell)
$env:OPENAI_API_KEY="sua-chave"

🐍 The included script

Python 3.9 or newer. No packages to install: the script uses only what’s already included with Python.

git clone https://github.com/inematds/gpt-image-26
cd gpt-image-26
python3 gerar.py --help
Usage guide · step by step

From your first prompt to a GIF and a logo

Steps 1 to 6 work in ChatGPT. Step 7 does the same thing through the API. All prompts are in prompts.md (in Portuguese).

1

Write your prompt in sections

Say what you’re making and how it will be used, then describe the scene, subject, details, and constraints. Put text that must appear in quotation marks, and say what you don’t want.

Create a portrait-format festival poster.
Scene: beach at sunset, golden light.
Details: bold typography, the same font across the whole poster.
Constraints: no logo, no watermark, no other text.
Text (exactly): "SEA FESTIVAL 2027"
2

Adjust complexity and quality one at a time

In ChatGPT, describe what you want in plain language (“plan the composition carefully,” “pay close attention to the small lettering”). In the API, use the complexity and quality fields. Compare runs with the same prompt, changing only one field.

# via the API (step 7): same prompt, change complexity only (quality stays fixed)
python3 gerar.py "Four dancers form the word LIKE" --complexity low  --quality medium --saida like-low
python3 gerar.py "Four dancers form the word LIKE" --complexity high --quality medium --saida like-high
3

Keep the same character

Describe the features that must stay the same and repeat them in every prompt. In ChatGPT, save the photo as a reference with a name, then call it by name later.

Save this image as a reference named "Ana".
# in a new conversation:
Use the reference "Ana" and create a video cover with the text "Start today".
4

Create a looping GIF

In ChatGPT, send the image and ask for a sprite sheet (a grid of animation frames): it draws the frames and assembles the GIF. Specify a starting pose to return to for a smooth loop; ask for more frames to make it smoother.

Create a 3x3 sprite sheet of this person blinking and smiling, in a loop.
The last frame returns to the first frame’s pose. Static camera. Then assemble the GIF.
5

Ask for the logo in SVG

SVG is vector: you can move it, recolor it, and scale it from phone size to a billboard. Open it in Inkscape or Figma. SVG is only available for new images (edits don’t return SVG).

Original logo for "Bread & Grain Bakery". Simple shapes, strong silhouette,
few colors, no gradients. Transparent background. Deliver as SVG.
6

Edit with markup: circle and ask

Mark the area in the image and describe the change. Then edit one thing at a time (color, background, lighting, angle), always saying what should stay the same.

Inside the red circle, paint the vase cobalt blue.
Change nothing else in the image. Remove the circle from the result.
7

Use the included script with the API

gerar.py builds the request with the correct field names and checks limits before spending (GIF frames, dimensions in multiples of 16, SVG generation only). Run it with --seco to preview the request without calling the API.

python3 gerar.py "Poster with the text \"SUMMER 2027\"" --modelo sunburst --quality high --seco
python3 gerar.py "Bakery logo, simple shapes" --formato svg --fundo transparente
python3 gerar.py "Cat blinks and returns to starting pose, static camera" --formato gif --quadros 9 --ms 200
# markup with the OpenAI example photo and circle
python3 exemplos/baixar.py
python3 gerar.py "Paint the vase inside the circle blue. Change nothing else. Remove the circle." --editar exemplos/cozinha.webp --markup exemplos/circulo.png --complexity low

For your own photo, create circulo.png in a layer editor (Photopea, Figma, GIMP): open the photo, create a new layer, draw the red circle, hide the photo layer, and export only the circle as a transparent PNG at the same size as the photo. Markup applies to the first image and can’t be combined with a mask. The photo can be PNG, JPG, or WebP.

Limits and cost

Where it still gets things wrong, and what it costs

It’s a real improvement in planning, text, crowds, GIFs, and vector graphics. Still, check the result before using it. The four cases below come from practical tests with 2.6; OpenAI lists text, consistency, and exact positioning as general limitations.

✋ Hands and wrists

It still leaves out fingers or reverses wrists, even at high quality.

📏 Proportions

It gets object scale wrong: Jupiter is too small, or playing cards come in different sizes.

🪞 Reflections

Mirrors show things they shouldn’t or leave out objects from the scene.

🔢 Counting

“Exactly seven” can turn into five. Check whenever the number matters.

Pricing

OpenAI charges by token, its unit for measuring what goes into and comes out of the model: a square image uses a few hundred to a few thousand tokens, depending on quality. Per token, 2.6 costs the same as 2.5 (output images cost US$30 per million tokens). The difference is how many tokens it uses: at low and medium quality, 2.6 uses more; at high and above, it uses the same amount.

Output cost for a 1024×1024 image, in US cents, from the official OpenAI calculator (checked on 11/07/2026). At low, 2.6 costs 4.2× more than 2.5; at medium, 3.3× more; from high up, they cost the same. The prompt text and input images add a little more.

To keep costs down: draft with Flare at low or medium quality; use Sunburst at high quality only for the final asset. Complexity and markup have no extra charge; SVG costs include the reference image and the vector tokens.
